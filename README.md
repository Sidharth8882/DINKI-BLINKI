# DINKI-BLINKI
*Its a 555 timer led blinker with custom made pcb and silkscreen. This blinker uses nine components to blink and adjust the led and uses 10 through hole led. The speed of the led blinker is can be controlled by a potentiometer. The project is fully made using web easyeda*

## WHY I MADE THIS

I made this led blinker because of the simplicity and the perfect guide that provided by hackclub forge. As a beginner its a good project start with . Eventhough i made some projects this is the one that i truly understand and the one i put much more effort and love.
